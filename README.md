# Pomodoro Focus

A lightweight desktop application designed to boost productivity and maintain user focus using the Pomodoro Technique. Built with C# and .NET Windows Forms, this application helps users effectively manage work intervals and short rest periods.

---

## Features

* **Dual Mode Tabs:** Dedicated tabs for **Focus Session** (25 minutes) and **Short Break** (5 minutes).
* **Intuitive Controls:** Simple and quick actions for **Start**, **Pause**, and **Reset** on each timer tab.
* **Clean Interface:** User-friendly Windows Forms GUI designed for seamless task management.

---

## Tech Stack

* **Language:** C#
* **Framework:** .NET 8.0 (Windows Forms)
